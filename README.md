## 👨‍💻 Sobre mim

Sou estudante de Sistemas de Informação e desenvolvedor FullStack com foco em produtos digitais, automação e soluções orientadas a IA. Trabalho com .NET, C#, JavaScript, React e integrações com modelos inteligentes para criar aplicações escaláveis, intuitivas e com boa experiência de usuário.

Minha trajetória combina desenvolvimento web, backend e interfaces, sempre com foco em entregar soluções simples, eficientes e com propósito real. Também trago uma forma diferente de pensar, fruto da minha experiência como pessoa neurodivergente, o que me ajuda a encontrar caminhos criativos e práticos para resolver problemas.
